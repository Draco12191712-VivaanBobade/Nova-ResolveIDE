# Security Policy

## Supported Versions

Nova Resolve IDE is an actively developed project. Security updates are provided for the latest stable release.

| Version | Supported |
|-----------|-----------|
| Latest stable release | Yea! |
| Older releases | Nah |
| Development builds | No guarantee |

Users are encouraged to keep their installations up to date.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.

Please do not disclose security issues publicly until they have been investigated and addressed.

When reporting a vulnerability, include:

- A clear description of the issue.
- Steps to reproduce the problem.
- The affected version of Nova Resolve IDE.
- Any proof-of-concept code or screenshots, if applicable.
- Your contact information, if you would like a response.

Security reports should provide enough information to allow maintainers to reproduce and verify the issue.

## Response Process

After receiving a report, the maintainers will:

1. Acknowledge receipt of the report.
2. Investigate the issue.
3. Determine the severity and affected components.
4. Develop and test a fix.
5. Release a security update when appropriate.
6. Publicly disclose the issue after a fix is available.

## Responsible Disclosure

Please:

- Avoid publicly sharing vulnerabilities before they are fixed.
- Avoid accessing, modifying, or deleting data that does not belong to you.
- Avoid disrupting services or intentionally causing harm.
- Act in good faith when performing security research.

## Third-Party Dependencies

Nova Resolve IDE depends on third-party libraries and services. Security vulnerabilities affecting dependencies may require updates from those projects before fixes can be released.

Dependencies should be kept up to date whenever possible.

## Extensions

Extensions are developed independently and may have their own security practices.

Users should install extensions only from trusted sources.

Extension authors are responsible for maintaining the security of their own projects.

## Supported Platforms

Security updates are intended for officially supported platforms and versions of Nova Resolve IDE.

Experimental builds and unofficial forks may not receive security fixes.
